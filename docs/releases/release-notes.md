# 更新记录

### 2026-08-31

- 新增面向五人组排的团队 BP 栏目，可结合队员位置、英雄熟练度、当前选禁状态以及蓝红方先后手生成英雄选择与禁用建议。
- 英雄强度数据固定使用 OP.GG 韩服翡翠及以上段位，并显示当前数据版本与更新时间。
- 新增 DeepSeek V4 Flash 战术分析，可在合法候选英雄范围内生成首选、备选、建议禁用和阵容说明；用户只需填写 API Key，凭证会在本机加密保存。
- 支持从已登录的 League Client 自动读取 Lobby、英雄选择、双方禁用和倒计时信息，并在我方操作阶段自动刷新建议。
- 团队 BP 现在会按当前回合的选择数量生成方案，并模拟剩余位置的最佳补全，以预计最终五人阵容而非局部英雄组合进行排序。
- OP.GG 详细对位胜率、样本量和协同证据会参与最终评分；小样本会向中性值收缩，无可靠证据时明确降低置信度。
